# ADR 004 — เกณฑ์มาตรฐานและเนื้อหาเป็นไฟล์ JSON ในที่เก็บโค้ด

- **Status:** accepted
- **Affects:** ตัวประเมินมาตรฐานและการเปลี่ยนแปลง, คลังเนื้อหา, เว็บแดชบอร์ด

## Decision

ตารางเกณฑ์มาตรฐาน คำอธิบายค่าตรวจวัดพร้อมข้อจำกัดในการตีความ และคำแนะนำการปฏิบัติตัว เก็บเป็นไฟล์ JSON ในที่เก็บโค้ดเดียวกับระบบ โดยผู้ใช้เป็นผู้ส่งเอกสาร JSON ให้ การแก้ไขผ่านการตรวจทานก่อนรวมโค้ด ระบบไม่มีหน้าจอผู้ดูแลหรือระบบจัดการเนื้อหา

## Why

- ทุกการแก้เกณฑ์หรือข้อความมีประวัติว่าใครแก้ เมื่อไร และใครตรวจ ซึ่งจำเป็นสำหรับคำแนะนำด้านสุขภาพถึงประชาชน
- เนื้อหาเปลี่ยนไม่บ่อย และ PRD ยังไม่ได้กำหนดระบบสำหรับผู้ดูแล
- ผู้ใช้ระบุว่าจะส่งเอกสารในรูปแบบ JSON ให้

ผลที่ตามมา: ผู้ที่ไม่ใช่นักพัฒนาแก้เนื้อหาเองไม่ได้ ต้องส่งให้ทีมแก้ และเนื้อหาใหม่ขึ้นเว็บในรอบประมวลผลถัดไป โครงสร้างของเอกสาร JSON ยังไม่ทราบจนกว่าจะได้รับเอกสาร

## Rejected

- **หน้าจอผู้ดูแลหรือระบบจัดการเนื้อหา** — ต้องเพิ่มการเข้าสู่ระบบ สิทธิ์ และฐานข้อมูลเนื้อหา สำหรับความต้องการที่ PRD ยังไม่มี
- **เก็บในตารางบนฐานข้อมูล GCP ต้นทาง** — ฐานข้อมูลนั้นเป็นของผู้ให้บริการข้อมูล และการแก้ตรงในตารางไม่มีขั้นตอนตรวจทาน
