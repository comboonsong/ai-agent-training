# ADR 002 — ที่วางระบบจริงและภาษาของงานประมวลผล

- **Status:** proposed
- **Affects:** เว็บแดชบอร์ด, งานประมวลผลข้อมูลตามรอบ, ชุดข้อมูลให้บริการ

## Decision

ข้อเสนอที่ยังไม่ได้รับการตัดสิน: วางระบบจริงบนบริการแบบมีผู้ดูแลให้บน GCP ทั้งหมด โดยไม่มีเครื่องเซิร์ฟเวอร์ที่ทีมดูแลเอง เว็บเป็นไฟล์สแตติกบนบริการโฮสต์ไฟล์ที่มี CDN ชุดข้อมูลให้บริการเป็นไฟล์ในที่เก็บไฟล์ของ GCP และงานประมวลผลรันตามกำหนดเวลาบนบริการรันงานของ GCP เขียนด้วย Python

สิ่งที่ผู้ใช้ตัดสินแล้ว: ช่วงนี้พัฒนาและสาธิตบนเครื่องของทีม โดยอ่านข้อมูลจาก GCP ส่วนที่วางระบบจริงสำหรับประชาชนยังไม่ตัดสิน

## Why

- ข้อมูลต้นทางอยู่บน GCP งานประมวลผลจึงอ่านได้ภายในผู้ให้บริการเดียวกัน โดยไม่ต้องเปิดฐานข้อมูลออกภายนอก
- ผู้ใช้ยืนยันเป้าหมายความพร้อมให้บริการ 99% ต่อเดือนตลอด 24 ชั่วโมง บริการที่ผู้ให้บริการดูแลรองรับเป้าหมายนี้โดยทีม Dev 2 คนไม่ต้องเฝ้าเครื่อง
- ไฟล์สแตติกผ่าน CDN ช่วยเป้าหมายประสิทธิภาพบนมือถือ
- Python มีเครื่องมืออ่านฐานข้อมูล GCP และ shapefile พร้อมใช้ ความคุ้นเคยของทีมกับ Python เป็นข้อสันนิษฐานที่ยังไม่ได้ยืนยัน

การออกแบบตาม ADR 001 ทำให้ระบบรันบนเครื่องของทีมได้ และย้ายขึ้นที่วางจริงภายหลังได้โดยไม่ต้องเปลี่ยนส่วนประกอบ บริการฐานข้อมูลต้นทางยังไม่ได้ตรวจสอบ ชื่อบริการเฉพาะจึงยังไม่ถูกเลือก

## Rejected

- **เครื่องเสมือนที่ทีมดูแลเอง** — ต้องดูแลระบบปฏิบัติการและแก้เองเมื่อเครื่องล่ม ซึ่งขัดกับเป้าหมาย 99% สำหรับทีมขนาดนี้
- **โฮสต์เว็บกับผู้ให้บริการรายอื่นนอก GCP** — เพิ่มบัญชีและผู้ให้บริการอีกราย โดยไม่ได้สิ่งที่ GCP ให้ไม่ได้
