# ADR 001 — เว็บอ่านชุดข้อมูลที่ประมวลผลล่วงหน้าตามรอบ

- **Status:** accepted
- **Affects:** เว็บแดชบอร์ด, งานประมวลผลข้อมูลตามรอบ, ตัวประเมินมาตรฐานและการเปลี่ยนแปลง, ตัวสร้างการแจ้งเตือน, ชุดข้อมูลให้บริการ

## Decision

งานประมวลผลอ่านตารางผลตรวจจาก GCP ตามกำหนดเวลา คำนวณสถานะเทียบมาตรฐาน การเปลี่ยนแปลงเทียบครั้งก่อน และการแจ้งเตือน แล้วเผยแพร่เป็นชุดไฟล์ข้อมูลที่เว็บแดชบอร์ดอ่านไปแสดง ระบบไม่มีเซิร์ฟเวอร์ API ที่ค้นฐานข้อมูลเมื่อมีคนเปิดหน้า

## Why

- ผลตรวจเปลี่ยนเฉพาะเมื่อมีรอบตรวจใหม่ จึงไม่จำเป็นต้องคำนวณใหม่ทุกครั้งที่มีคนเปิดหน้า
- ประชาชนอ่านอย่างเดียว ไม่มีการเข้าสู่ระบบ ทุกคนเห็นข้อมูลชุดเดียวกัน
- ผู้ใช้ยืนยันเป้าหมายประสิทธิภาพ 5 วินาทีที่อย่างน้อย 95% ของการเปิดหน้า การโหลดไฟล์ที่เตรียมไว้แล้วทำให้เป้าหมายนี้ไม่ขึ้นกับความเร็วของฐานข้อมูลต้นทาง
- เมื่อฐานข้อมูลต้นทางใช้งานไม่ได้ แดชบอร์ดยังแสดงชุดล่าสุดที่เผยแพร่ไว้
- ทีม Dev 2 คนมีส่วนที่ต้องดูแลน้อยลง

ผลที่ตามมา: ผลตรวจใหม่ปรากฏบนแดชบอร์ดช้ากว่าต้นทางได้ไม่เกินหนึ่งรอบประมวลผล และงานของ Dev 2 ในแผนแบ่งงานทีมเปลี่ยนจากการพัฒนา API เป็นงานประมวลผลและชุดข้อมูลให้บริการ

## Rejected

- **API ที่ค้นฐานข้อมูลสดทุกคำขอ** — ต้องมีเซิร์ฟเวอร์ทำงานตลอดเวลา ความเร็วและความพร้อมของเว็บผูกกับฐานข้อมูลต้นทาง และต้องคำนวณซ้ำสำหรับข้อมูลที่ไม่ได้เปลี่ยนระหว่างรอบตรวจ
