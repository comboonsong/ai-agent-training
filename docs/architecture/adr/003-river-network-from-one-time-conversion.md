# ADR 003 — โครงข่ายลำน้ำจากการแปลง shapefile ครั้งเดียว

- **Status:** proposed
- **Affects:** โครงข่ายลำน้ำ, ตัวสร้างการแจ้งเตือน, เว็บแดชบอร์ด

## Decision

ข้อเสนอที่ยังไม่ได้รับการตัดสิน: แปลง shapefile ลำน้ำครั้งเดียวล่วงหน้า เป็นไฟล์ข้อมูลสองชุดที่เก็บไว้กับโค้ด ได้แก่ แนวลำน้ำพร้อมทิศทางสำหรับแผนที่และภาพเคลื่อนไหวการไหล และตารางลำดับจุดตรวจที่ระบุว่าจุดใดอยู่ท้ายน้ำของจุดใด ซึ่งตัวสร้างการแจ้งเตือนใช้ คนตรวจและแก้ไขทั้งสองชุดได้โดยตรง

สิ่งที่ผู้ใช้ระบุ: ผู้ใช้จะเป็นผู้ระบุทิศทางการไหล หลังทีมตรวจข้อมูลร่วมกัน การตัดสินใจนี้จึงรอผลการตรวจข้อมูล

## Why

- ลำน้ำและตำแหน่งจุดตรวจแทบไม่เปลี่ยน จึงไม่ต้องคำนวณโครงข่ายใหม่ทุกรอบ
- การแจ้งว่าจุดใดอาจได้รับผลกระทบเป็นข้อความถึงประชาชน ตารางลำดับที่คนตรวจได้ด้วยตาลดโอกาสแจ้งเตือนผิดจุด
- ใช้ได้แม้ shapefile ไม่มีข้อมูลทิศทาง PRD ยังเปิดประเด็นนี้ไว้และยังไม่มีใครตรวจไฟล์ การให้ผู้ใช้ระบุทิศทางเข้ากับแนวทางนี้
- ไม่ต้องเพิ่มฐานข้อมูลเชิงพื้นที่

ผลที่ตามมา: เมื่อเพิ่มหรือย้ายจุดตรวจ ต้องมีคนแก้ตารางลำดับเอง ขอบเขตจุดท้ายน้ำเมื่อลำน้ำมีทางแยกยังเป็นประเด็นเปิด

## Rejected

- **คำนวณโครงข่ายลำน้ำอัตโนมัติด้วยฐานข้อมูลเชิงพื้นที่ทุกรอบ** — เพิ่มระบบอีกตัวที่ต้องดูแล และต้องพึ่งคุณภาพของ shapefile ที่ยังไม่ได้ตรวจ ผลที่ผิดจะกลายเป็นการแจ้งเตือนผิดจุดโดยไม่มีคนเห็น
